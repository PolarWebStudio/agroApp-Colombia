# 🌾 AgroRed Colombia - Progressive Web App (PWA)

AgroRed Colombia es una aplicación web progresiva diseñada para apoyar a agricultores, campesinos y compradores locales con herramientas financieras simples y consulta de precios de mercado sin necesidad de conexión a internet.

## 🚀 Características
* **Calculadora de Márgenes:** Evalúa ganancias netas y costos de producción antes de negociar con intermediarios.
* **Precios de Referencia (Plazas):** Listado de precios de productos agrícolas con opción para agregar y editar precios de mercados locales en tiempo real.
* **Mis Cosechas:** Cuaderno de notas local para registro de insumos y siembras.
* **Soporte Offline Completo:** Funciona sin señal de internet mediante Service Worker y LocalStorage.

## 🛠️ Tecnologías
* HTML5 / CSS3 (CSS Variables y Diseño Responsivo)
* JavaScript Vanilla (ES6+)
* Service Workers & Web App Manifest (PWA)
